Contact PityHub

PityHub has no email address and no social media accounts. The only way to contact the site is through its public code repository:

GitHub Issues — the way to reach us

Open an issue on the PityHub repository: github.com/babyboovn01-prog/nte-zzz-hub/issues (repository: babyboovn01-prog/nte-zzz-hub). You will need a free GitHub account to post.

Bug reports and corrections are welcome

Please report anything that is wrong — it helps every visitor. Useful reports include:

  • Wrong data — a wrong rate, date, stat, tier, or code (say which page, and link the correct source if you have one).
  • Missing or broken images — which character or item, and on which page.
  • Bugs — a simulator, tracker, calculator, or menu that does not work (say which page, your browser, and what happened vs what you expected).
  • New information — a new banner, code, or character that should be added.

There is no promised reply time — this is a small fan-made site, run by one person in their spare time — but every issue is read.

What not to send

Please do not post your game account details, passwords, or any personal information in a public issue. PityHub never needs your game login for anything, and no one from the site will ever ask for it.
