Damage Calculator — Estimator

Compare builds quickly: enter a character's ATK, CRIT Rate, CRIT DMG and DMG Bonus. Works the same way for NTE and ZZZ builds, because it uses only the shared formula below.

This is an estimator, not game-accurate damage. It does NOT model enemy DEF, elemental RES, skill multipliers per hit, anomaly / disorder, buffs, debuffs, or each game's real damage formula. Use it to compare two builds of the same character, not to predict exact in-game numbers.

Formula: base = ATK × (1 + DMG Bonus) × Skill Multiplier. Non-crit hit = base. Crit hit = base × (1 + CRIT DMG). Expected hit = base × (1 + CRIT Rate × CRIT DMG).

Example — compare two builds

Build A: ATK 2,000, CRIT 60% / 120%, DMG Bonus 30%, skill 100% → expected hit ≈ 4,472.
Build B: ATK 2,200, CRIT 50% / 150%, DMG Bonus 30%, skill 100% → expected hit ≈ 5,005 — Build B wins on expected damage despite lower CRIT Rate. Try your own numbers above.
